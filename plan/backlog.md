## 근거표 (2027 丁未年, 미토 본기 = 기토)
| 일간 | 丁(천간) | 未(지지) |
|---|---|---|
| 갑목 | 상관 | 정재 |
| 을목 | 식신 | 편재 |
| 병화 | 겁재 | 상관 |
| 정화 | 비견 | 식신 |
| 무토 | 정인 | 겁재 |
| 기토 | 편인 | 비견 |
| 경금 | 정관 | 정인 |
| 신금 | 편관 | 편인 |
| 임수 | 정재 | 정관 |
| 계수 | 편재 | 편관 |
십성 뜻(부드럽게): 식상=표현·재능·부업 / 재성=돈·기회 / 관성=책임·직장·인연(여성 기준 이성) / 인성=공부·문서·도움 / 비겁=동료·경쟁·자존심

띠와 未: 午 육합(오미합) / 亥·卯 삼합(해묘미) / 巳 방합(사오미, 화 기운) / 丑 충(축미충) / 戌 형(축술미 삼형) / 子 원진·육해(서운함·오해 주의) / 未 본명년 / 寅·辰·申·酉 특별한 합충 없음(일반 덕담 톤). 띠는 입춘 기준.
